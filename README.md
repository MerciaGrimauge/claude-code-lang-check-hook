# claude-code-lang-check-hook

Claude Code の応答が英語に崩れていないかを調べるフックです。
ユーザーに見える Claude の文が英語になっていると、日本語で書き直すよう Claude に伝えます。

## 何をするか

`lang_check.py` は、Claude Code の会話記録（transcript）から Claude の文を読み、英語になっていないかを調べます。

- `stop`（Stop フック）: 応答の最後に、まだ調べていない文が英語なら、応答を差し戻して日本語で書き直させます。
  止まらなくなるのを防ぐため、同じ応答での差し戻しは 1 回だけです（`stop_hook_active` が立っていれば差し戻しません）。
- `tool`（PostToolUse フック）: ツールを呼んだ後、直前の途中経過の文が英語なら、Claude に注意を返します。作業は止めません。

## 判定のしかた

- 英字 ÷（英字 + 日本語の文字）が **0.8 を超え**、数えた文字が **40 以上** のとき、英語と判定します。
- 次の物は数えません。
  - コードブロック（```` ``` ```` で囲んだ部分）
  - バッククォートで囲んだインラインのコード
  - URL（`http://`・`https://`・`claude://`）と、Markdown のリンク先
  - ファイルのパス（ドライブ名で始まる物、`/`・`\`・`~/` で始まる物、`a/b` のような区切りを含む物）
- 日本語の文字は、ひらがな・カタカナ・漢字・半角カタカナです。

## 導入

1. `lang_check.py` を、たとえば `~/.claude/hooks/` に置きます。
2. ユーザー設定（`~/.claude/settings.json`）またはプロジェクト設定（`.claude/settings.json`）の `hooks` に、
   Stop と PostToolUse を登録します。

```json
{
  "hooks": {
    "Stop": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "python \"<lang_check.py のパス>\" stop",
            "timeout": 20
          }
        ]
      }
    ],
    "PostToolUse": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "python \"<lang_check.py のパス>\" tool",
            "timeout": 20
          }
        ]
      }
    ]
  }
}
```

`python` が見つからない環境では、`<Python のパス>` のように Python の実行ファイルを直接書いてください。
既に `hooks` があるときは、その中に `Stop` と `PostToolUse` の項目を足してください。

## `state` フォルダ

スクリプトと同じ場所に `state` フォルダが自動で作られ、セッションごとに調べ終えた文の記録（`<セッション ID>.json`）が置かれます。
同じ文を何度も調べないためのものです。記録はセッションごとに最新の 2,000 件までです。
途中からフックを入れたセッションでは、それまでの文は調べず、最新の 1 つだけを調べます。

`state` フォルダは消しても動作します（次に動いたとき作り直されます）。

## 無効にする

設定の `hooks` から、`lang_check.py` を呼ぶ Stop と PostToolUse の項目を消してください。
一時的に止めるときは、Claude Code の `/hooks` から確認・編集することもできます。

## 注意

- 英語で応答してほしいプロジェクトでも、英語の応答は差し戻されます。そのようなプロジェクトでは、
  ユーザー設定ではなく、日本語で応答させたいプロジェクトの設定にだけ登録してください。
- 差し戻しと注意の文は、「途中経過も含めてすべて日本語（です・ます調）で書く決まり」という前提で書かれています。
- 判定は文字の割合だけで行うため、英語の引用や識別子が多い文は、日本語の文でも英語と判定されることがあります。
